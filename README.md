# x-autopilot-updates

Auto-update feed for [X-Autopilot](https://xautopilot.app) — the Twitter/X growth agent for Mac.

`appcast.xml` is the Sparkle-format feed the running app polls every 24h. Signed/notarized DMG binaries are attached as release assets — see the Releases tab.

Download links and product info: [xautopilot.app](https://xautopilot.app/download)
